# BabyBloom — админка

Laravel 12 + Vue 3 (Inertia) + MySQL, всё в Docker.

## Запуск

```bash
docker compose up -d
```

Открыть: http://localhost:8080 (логин и пароль — `ADMIN_EMAIL` / `ADMIN_PASSWORD` в `.env`).

| Сервис | Что это | Порт |
|---|---|---|
| `app` | PHP 8.3-FPM + Composer + Node | — |
| `nginx` | веб-сервер | 8080 |
| `mysql` | MySQL 8.4 (БД `babybloom`) | 3307 |
| `vite` | Vite dev-сервер (Vue, горячая перезагрузка) | 5173 |

## Первый запуск на новом компьютере

```bash
cp .env.example .env
docker compose up -d
docker compose exec app composer install
docker compose exec app php artisan key:generate
docker compose exec app php artisan storage:link
docker compose exec app php artisan migrate --seed
```

## Полезные команды

```bash
docker compose exec app php artisan migrate          # новые миграции
docker compose exec app php artisan migrate:fresh --seed  # ⚠ стереть всё и загрузить начальные данные заново
docker compose exec app npm run build                # собрать фронт для продакшена
docker compose logs -f vite                          # логи Vite
docker compose down                                  # остановить
```

## Разделы

- **Главная** — продажи, закупки, расходы и прибыль за месяц; склад; открытые заказы.
- **Касса** — сколько денег сейчас и история всех движений с датами: «было → −3 000 → осталось». Новые расходы, закупки и продажи попадают сюда автоматически; старые данные уже учтены в начальном остатке.
- **Товары** — каталог: фото, цены (¥, ֏, доставка, продажа), размеры, цвета, ссылка Pinduoduo.
- **Закупки** — заказ (Pinduoduo / оптовик) с несколькими товарами: фото, ссылка, цены в ¥ и ֏, размеры и цвета. Общая доставка делится поровну на каждую штуку. Новые товары сразу попадают в «Товары» и на склад со статусом «В пути»; потом закупки (или отдельные штуки на складе) можно массово отметить «Доставлено».
- **Склад** — каждая штука отдельно (размер, цвет, статус: в наличии / в обработке / бронь / продан). Кнопка «Продать» сразу создаёт запись в продажах.
- **Заказы** — заказы клиентов (адрес, телефон, сумма, выполнен).
- **Продажи** — все продажи, выручка и прибыль за месяц.
- **Расходы** — реклама, доставка, упаковка и прочие траты.

Прибыль на главной = продажи − закупки − расходы.
